# Blades Of Eternity

A console-based roguelike RPG written in C++.

Fight through endless rooms filled with randomly generated enemies, level up your hero, learn powerful skills, and see how far you can survive.

## Features

- 3 unique playable characters:
  - Kael Stormblade — Balanced fighter
  - Brakka Ironfist — Tank with high survivability
  - Lyra Nightwhisper — Mage with high damage
- Randomly generated enemies in every room
- Turn-based combat system
- Multiple skill types:
  - Attack
  - Defense
  - Heal
  - Freeze
- Energy system for using skills
- Character progression and leveling system
- Upgrade choices after leveling up:
  - Learn a new skill
  - Upgrade an existing skill
  - Increase max HP
  - Increase max Energy 
- Endless dungeon progression

## Gameplay

Your goal is simple:
Survive as many rooms as possible.

Each room contains random enemies. Defeat them using your skills and strategy.
After clearing a room, you gain experience and become stronger over time.

Choosing the right upgrades and managing your energy carefully is the key to survival.

## Controls

Controls are handled using the number keys (1-0).

All key bindings are displayed directly in the game interface

## Installation & Running

### Requirements
- C++ compiler

### Running the game
- Open the project in Visual Studio
- Build the solution
- Run the project
